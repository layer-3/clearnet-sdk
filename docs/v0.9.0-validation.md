# v0.9.0 validation record

Local validation on 2026-10-16. These results apply to the working changes based
on SDK commit `1c5b3bf749857f95cc6aff3c99d80d6b4060cdfb` and companion Clearnet
commit `80b99ff99a7e7a20d089f75e65a3530f86611650`. They are not GitHub CI results
for committed release revisions and do not authorize publication.

## Review concerns addressed in source

- Go and TypeScript prepared intents retain the canonical catalogue fingerprint.
  Signing and submission reject changed or missing metadata, including after JSON
  persistence. Tests cover decimal, backing-chain/address, native-asset, fee-token
  precision and removed-asset changes. Explicit CLI catalogue review preserves
  the original encrypted journal and signed wire authorization.
- The gateway reports retained routing-window evidence through `pendingUntil`,
  including after peer outages. Identical replay can reconcile to a verified
  receipt; elapsed time alone never establishes rejection. Operator backfill can
  request history from before a missed seal and still enforces Registry/BLS
  verification. The [recovery runbook](../cmd/yellow/RECOVERY.md) ships in every
  CLI archive.
- Clearbox now uses production fixed-point **base-unit** prices. The wallet
  values holdings with exact ratios, handles differing token decimals and uses
  the gateway's effective `transferPrice` for EMA-based fees. Missing fee metadata
  requires an approved explicit cap. The npm manifest and lockfile identify 0.9.0.

## Outstanding release gates

- **Bitcoin and Solana local-chain integration:** attempted an isolated devnet
  on separate ports because another project already used the defaults. Docker
  reported `No space left on device` while creating both ledgers. Neither chain
  became ready; their Go/TypeScript integration suites were not run. Free space
  through the normal operator process and rerun `make devnet` / `make integration`
  in a suitable isolated environment. Existing Docker data was not pruned and the
  temporary SDK test stack was removed. Packed Solana smoke checks and unit tests
  do not substitute for this gate.
- Commit/review the SDK and companion gateway changes and require full GitHub CI
  on the exact release revisions, including the pinned Forge and Node toolchains.
- Deploy the companion gateway changes before claiming v0.9.0 recovery and
  automatic non-YELLOW fee-estimation support. Record the deployed revision.
- Deployed-gateway recovery/pricing and real-wallet browser acceptance were not
  exercised. Keep them outstanding, or record an explicit release-owner decision
  to defer them and disclose the unvalidated behavior in release notes.
